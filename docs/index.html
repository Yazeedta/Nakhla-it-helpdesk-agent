This page is an interactive simulated portfolio demonstration, not the hosted production AI agent. It uses predefined, fictional scenarios and never contacts OpenRouter, the helpdesk API, MCP services or an actual employee account. The real local project has a Gradio interface, FastAPI backend, RAG and MCP integration.

HOW IT WORKS

Connected, grounded, human-controlled.

From employee request to a policy-checked answer, with tool traces and optional approval.

Knowledge ingestion

Markdown and PDF documents are chunked, embedded and stored for retrieval.

RAG + reasoning

Relevant knowledge and current policies guide responses. The hybrid agent handles specialized flows.

MCP tools

Simulated directory, service status and ticket tools provide verified operational context.

Approval gate

Ticket actions require explicit human approval before any write is attempted.
